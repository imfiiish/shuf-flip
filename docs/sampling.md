# 抽样逻辑：级联窗口（cascading windows）

> 本文描述 Study 页「一轮」的抽词逻辑与公式。当前参数：**R=16、W=64、g=4、n=8、m=3**。

## 1. 要解决的问题

现在的做法是「整池洗牌取前 R 个」，每轮独立均匀。于是**同一个词隔多久再见 ≈ N/R 轮**，池子越大越碰不到老词：

| 池子 N | 每词每轮出现率 R/N | 相邻两轮≥1 个重复 | 隔多少轮再见同一词 |
|---:|---:|---:|---:|
| 50 | 32% | 99.96% | 3 轮 |
| 2000 | 0.80% | 12.1% | 125 轮 |
| 10000 | 0.16% | 2.5% | 625 轮 |

目标：**不管 N 多大，都让「学到的词」保持稳定、够高的重复率**（熟悉感），同时长期又能覆盖全部词。

## 2. 两条关键性质

1. **均匀的复合还是均匀**：如果每一级窗口每轮都重新随机抽，那么「从 N 抽大池 → 抽中池 → 抽小池 → 抽 R」和「直接从 N 抽 R」完全等价。**级联只有在下级窗口被保留若干轮时才有效。**
2. **窗口只改变时间分布**：只要窗口是均匀轮换的，全局平均「每词每轮出现率」恒为 `R/N`，怎么级联都不变。窗口真正改变的是**把出现聚成堆**（短期密集重复）。

## 3. 参数

| 符号 | 值 | 含义 |
|---|--:|---|
| `R` | 16 | 每轮张数（`ROUND_SIZE`） |
| `W` | 64 | **活跃窗口**（每轮实际从这 64 个里抽） |
| `g` | 4 | **词数倍率**（上一级窗口是下一级的几倍） |
| `n` | 8 | 活跃窗口寿命（轮） |
| `m` | 3 | **周期倍率**（每级周期 = 下级周期 × m，与 `g` 解耦） |
| 链 | `64,256,…,≤N` | 级联的池子大小（逐级 ×g，顶部必要时补半池级，再接到总池 N） |

## 4. 公式

1. **窗口内每词每轮出现概率**

   ```
   P = R / W = 16 / 64 = 25%
   ```
   这就是「锁 25%」——锁定的是**窗口内**的概率。

2. **一个窗口寿命内，每词平均出现次数**

   ```
   k = n · R / W = n / 4 = 2
   ```

3. **第 i 级窗口的周期**（i=0 是最小的 64，按层号而不是按词数）

   ```
   T_i = n · m^i        // 链 64,256,1024,2048,… → 8,24,72,216,…
   ```

4. **相邻两个同级窗口的重叠**（均匀抽，父级 P、子级 W）

   ```
   E[重叠] = W² / P        // 例：从 256 抽 64 → 64²/256 = 16，即延续 25%
   ```

## 5. 算法

```
levels = [64, 256, 1024, ...] 再接到总池 N        # 逐级 ×g；顶部必要时补半池级
period[i] = n * m^i                               # 第 i 级多久换一次（按层号）
cur[i]   = 第 i 级当前的那一撮词

初始化（从顶往下）:
  cur[top] = 全部 N 个词
  for i = top-1 .. 0:  cur[i] = cur[i+1] 里均匀随机抽 size[i] 个

每一轮:
  for i = top-1 .. 0:                             # 先刷高层，再让低层从新高层抽
    if t % period[i] == 0:  cur[i] = cur[i+1] 里均匀随机抽 size[i] 个
  round = cur[0] 洗牌取 R 个
```

## 6. 时间线示例（N=3000，m=3，链 64→256→1024→2048→3000）

```
t=0    抽 64 256 1024 2048（从 3000 逐级往下抽）
t=8    换 64
t=16   换 64
t=24   换 256, 64          ← 256 活了 3 个"8轮"
t=32   换 64
...
t=72   换 1024, 256, 64    ← 1024 活了 3 个"24轮"
...
t=216  换 2048, 1024, 256, 64
...
t=432  换 2048, …（每 216 轮一次，从 3000 重抽）
```

每个上级窗口（周期 `T_{i+1}=m·T_i`）里，下级换 `m` 次。

## 7. 实测（N=3000，R=16，n=8，g=4，链 64→256→1024→2048→3000）

倍率 m 只影响「覆盖速度」；窗口内 25% 与 m 无关。

| m | 各级周期 | 1000 轮覆盖 | 2000 轮覆盖 | 5000 轮覆盖 |
|--:|---|---:|---:|---:|
| 2 | 8,16,32,64 | 87.3% | 98.3% | 100.0% |
| **3** | 8,24,72,216 | 80.9% | 96.3% | 100.0% |
| 4 | 8,32,128,512 | 71.2% | 91.7% | 99.8% |

其它指标（m=3）：每轮旧词占比 前 50 轮 ~67% → 1000+ 轮 ~94%；窗口内每词每轮恒 25%。

## 8. 调参指南

| 想改什么 | 调哪个 |
|---|---|
| 重复率（窗口内锁多少） | `W`：R/W = 25% → W=64；要 12.5% → W=128 |
| 窗口内重复几次 | `n`：`n/4` 次（n=8 → 2 次） |
| 熟悉 ↔ 覆盖 的取舍 | `m`：越大越黏（覆盖慢），越小越快铺开 |
| 每级跨度（越大铺得越快、越跳） | `g`：4 → 64,256,1024…；2 → 64,128,256… |
| 覆盖范围 | 链的层数和总池 `N` |

> 注意：全局平均每词出现率永远是 `R/N`，级联改不了它；级联只决定「什么时候扎堆出现」。
