username 打字动画 · 对比

密码圆点是 transition 180ms ease 的缩放+变色（你满意的那档，已放在左上角作参照）。
下面是 username 逐字的不同入场方式，报编号我就换；想混搭也行（比如「v3 的缩放 + v6 的机制」）。

参照 · 密码圆点满意
transition: background/transform 180ms ease；圆点始终在位，只在“填充”时平滑放大变色。
v1 · 当前（缩放入 0.7）
scale .7→1 + 淡入，180ms ease。缩放幅度偏大，最“弹”。
v2 · 微缩淡入 0.85
幅度收小到 15%（和圆点同级），柔和很多。
v3 · 放大回落 1.15→1
不淡入，字直接以 115% 出现再收回正常。最接近圆点“放大”的方向。
v4 · 纯淡入
只改透明度，没有位移/缩放，最安静。
v5 · 上浮淡入
从下往上浮入（之前的版本）。
v6 · 密码同款机制
用 @starting-style + transition（和圆点同一套过渡机制），0.8→1 + 淡入。
v7 · 无动画
字直接出现。最“原生”、最顺，但没有任何入场感。
